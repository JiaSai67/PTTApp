# 按鍵發話 (PTT) 控制器

這是一個基於 Python 與 PySide6 (Qt) 開發的麥克風控制工具。它可以讓你像在 Discord 一樣，透過設定全域快捷鍵來實作「按住發話」或「一鍵開關麥克風」的功能。最棒的是，它可以精準靜音你所指定的特定應用程式麥克風輸入（例如遊戲內語音、直播軟體等）。

## 系統需求
- Windows 10 / 11
- Python 3.9 以上版本

## 安裝與執行方法

本專案完全符合 **AI Tool Launcher** 開發規範，支援隨插即用與自動化環境建置。

1. **一鍵註冊與安裝**
   將專案下載或 `git clone` 至本地後，直接雙擊執行目錄下的 `linkme.bat`。
   這會將本工具註冊至你的 AI Tool Launcher 啟動器中。

2. **啟動程式**
   打開你的 AI Tool Launcher，在工具清單中找到「**按鍵發話控制器 (PTTApp)**」並點擊啟動。
   啟動器會**自動幫你安裝** `requirements.txt` 中所需的所有依賴套件（如 `PySide6`, `pycaw`, `pynput` 等），完全不需要手動下達任何 `pip install` 指令！

3. **自動更新**
   當 GitHub 有新版本時，只需在啟動器點擊「🔄 重新拉取」，啟動器即會自動執行更新與環境同步。

## 功能特色
- **自訂快捷鍵**：支援組合鍵以及滑鼠按鍵 (如側鍵、中鍵等)。
- **支援兩種模式**：
  - **模式 1 (按住發話)**：按下按鍵時解除靜音，放開時靜音。
  - **模式 2 (切換模式)**：按一下靜音，再按一下解除靜音。
- **懸浮圖標提示**：在畫面上顯示目前的麥克風狀態，並且支援自由拖曳調整位置。
- **針對性靜音**：只會干預你勾選的應用程式音訊通道，不會影響系統全局麥克風或其他背景音樂。

## 疑難排解
- **如果發現某些按鍵無法攔截**：請嘗試以「系統管理員身分」執行該腳本。
- **如果清單中沒有出現你想控制的應用程式**：請確認該應用程式目前有在背景使用音效裝置，然後點擊「重新整理清單」。
